The directory /root/work/cifs contains two CIF files describing independent conventional cells. Each atom-site loop lists an element symbol, Wyckoff multiplicity, and site occupancy. A row represents one crystallographic orbit: its contribution to the cell's element count is multiplicity times occupancy. Different rows can have the same element, and vacancies are represented only by occupancies below one. Do not count an atom-site row as just one atom, and do not normalize the resulting composition to a formula unit.

Calculate the effective conventional-cell count for every element appearing in each file by summing those contributions. Occupancies are exact decimal numbers for this exercise. The fractional coordinates and atom labels supply context but do not change the count. Each CIF is processed separately, even when an element occurs in both files.

Write exactly one UTF-8 tab-separated file at /root/work/cell_composition.tsv. Its first line must be `file`, `element`, `effective_atoms`, separated by tabs. Follow it with one row per file–element pair, sorted first by CIF basename and then alphabetically by element symbol. Use the basename including `.cif`, and format every effective count with exactly three digits after the decimal point, in atoms per conventional cell. Include no totals, comments, blank lines, or additional columns.
