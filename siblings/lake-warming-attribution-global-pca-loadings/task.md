# Shared variation in lake drivers

Four annual CSV files under `/root/work/` describe the same lake and have one row per `Year`: `climate.csv` contains `AirTemp`, `Radiation`, and `WindSpeed`; `hydrology.csv` contains `Inflow` and `Runoff`; `land_cover.csv` contains `DevelopedPct`, `AgriculturePct`, and `TreeCoverPct`; and `water_temperature.csv` contains `WaterTemp`. The temperature file provides context but is not an input to this calculation. Join the driver files by `Year`, not by row position.

Run one principal-component analysis on all eight driver columns together, in the order just listed. Standardize each column by subtracting its mean and dividing by its population standard deviation (ddof=0). Use the eigenvectors of the standardized matrix's covariance matrix, calculated with divisor N. Order components by descending eigenvalue. For PC1, reverse its sign if the loading with greatest absolute magnitude is negative.

Write exactly `/root/work/pca_summary.json`. It must contain `pc1_variance_pct` and `pc2_variance_pct` (each eigenvalue divided by the sum of eigenvalues, times 100), `pc1_loadings` (an object mapping every driver name to its signed PC1 eigenvector entry), `dominant_category`, and `category_share_pct`. Categories are Heat (`AirTemp`, `Radiation`), Flow (`Inflow`, `Runoff`), Wind (`WindSpeed`), and Human (the three land-cover columns). A category's share is 100 times the sum of its squared PC1 loadings; report the category with the largest share. Round every numeric output to six decimal places.
