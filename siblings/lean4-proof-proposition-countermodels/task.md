# Audit propositional proof claims

`/root/work/claims.json` is a JSON array of claims. Each claim has a unique string `id` and an expression `formula`. A formula is an AST: `{"var":"a"}` names a Boolean variable; `{"not":F}` negates a formula; and `{"and":[F,G]}`, `{"or":[F,G]}`, or `{"imp":[F,G]}` combines two formulas. An implication is false only when its left operand is true and its right operand is false. All claims use the same four variables, `a`, `b`, `c`, and `d`, although a particular formula need not mention all four.

Determine which claims hold under every assignment. Write exactly `/root/work/countermodels.json`, a JSON array in input order. Each entry must have exactly `id`, `valid`, and `counterexample`. `valid` is a JSON boolean. For a valid formula, `counterexample` is `null`. Otherwise it is an object with all four variable names as keys and JSON boolean values, giving the first falsifying assignment in lexicographic order of `(a,b,c,d)`, with `false` preceding `true`. Include values for unused variables as well. Interpret the AST using ordinary two-valued propositional logic; neither file contains Lean syntax, and no rounding or numerical tolerances apply.
