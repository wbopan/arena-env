## Reference notes

Use Python’s standard-library `struct`, `hashlib`, and `json` for byte-accurate extraction. `tshark -r /root/work/telemetry.pcap -Y http.request -T fields -e ip.src -e tcp.srcport -e http.request.method -e http.request.uri` can provide a quick visual summary if available, but parse and hash the reassembled bytes yourself: an HTTP display filter is not a substitute for handling out-of-order TCP segments.

- **Classic little-endian libpcap:** Read the 24-byte global header, then repeat: 16-byte packet header (`struct.unpack('<IIII', ...)` gives timestamp seconds, fractional timestamp, captured length, original length), followed by exactly `captured length` bytes. Check the global magic and Ethernet link type before parsing. Do not interpret per-packet lengths as network-endian.
- **Ethernet / IPv4 / TCP:** Ethernet’s EtherType is at bytes `12:14` (IPv4 is `0x0800`). IPv4 starts at offset 14; its header length is `(first_byte & 0x0f) * 4`, and protocol 6 is TCP. IPv4’s total length bounds the IP packet, even if the captured frame has extra bytes. TCP’s header length is `((tcp_byte_12 >> 4) & 0x0f) * 4`. Read multibyte IP/TCP fields in **network byte order** (`'!'` or `'big'`). TCP payload starts after that TCP header. Keep only client-to-server packets with destination port 80 and a nonempty payload.
- **Reassembly:** Group by connection (the source port is unique here); retain each payload with its numeric TCP sequence number. Sort *within each connection by sequence number*, not capture order, then concatenate. SYNs and packets without payload contribute no request bytes. Given no retransmissions or sequence wraps, numeric sorting suffices.
- **HTTP bytes:** Split the assembled request at its first `b'\r\n\r\n'`. Parse the method and URI from the first header line; read `Content-Length` case-insensitively from the header lines. Starting immediately after the separator, take **exactly** that many bytes as the body. Check that enough bytes were captured; do not hash subsequent traffic. Use `hashlib.sha256(body).hexdigest()` (also valid for `b''`).

For output, construct dictionaries with only `src_ip`, `src_port`, `method`, `uri`, `body_bytes`, and `body_sha256`; sort with `key=lambda row: row['src_port']`, then write the array with `json.dump(...)`. Keep payloads as bytes until after hashing; decode only the textual request-line/header fields needed for JSON.
