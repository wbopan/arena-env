# Build a Keep-Interval Edit Plan

A recording's duration is recorded in `/root/work/recording.json`. Two detectors have proposed portions to remove: `/root/work/opening.json` and `/root/work/pauses.json`. Each detector file has a `segments` array whose entries have integer `start` and `end` times in seconds. Intervals are half-open: `[start, end)`. The detector proposals can overlap, touch, or extend beyond the recording's boundaries.

Produce exactly one file, `/root/work/keep_plan.json`. First clip every proposed removal interval to `[0, duration_seconds)`, discarding any interval that is empty after clipping. Remove the **union** of the clipped intervals: overlapping or touching removals must not count twice. The keep intervals are the nonempty gaps in that union, ordered from earliest to latest. Do not add padding around cuts.

The output is a JSON object with exactly `original_duration_seconds`, `removed_duration_seconds`, `output_duration_seconds`, and `keep_segments`. Durations are integer seconds. `keep_segments` is a list of objects, each with exactly integer `start`, `end`, and `duration` fields; duration equals end minus start. `removed_duration_seconds` is the size of the removal union, and `output_duration_seconds` is the sum of keep durations. Thus original duration equals removed plus output duration. This is an edit decision plan, not a request to render a video.
